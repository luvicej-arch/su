# 말글 — 우리말 놀이터

DESIGN.md의 흰 바탕, 인디고 포인트, 가벼운 큰 제목, 파스텔 콜라주를 반영한 로컬 전용 맞춤법 미니게임 포털입니다.

## 실행

Node.js가 있는 환경에서 이 폴더를 터미널로 연 다음 실행합니다.

```sh
npm run dev
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 서버는 내 컴퓨터의 루프백 주소에만 연결합니다. 종료는 터미널에서 Ctrl+C입니다. 설치할 패키지는 없습니다. dist/index.html 파일을 직접 열어서 사용할 수도 있지만, 기록 보존은 로컬 서버 실행을 권장합니다.

## 기능

- 맞춤법 두 가지 중 선택 / 띄어쓰기 / OX / 30초 퀴즈
- 정답 해설, 결과, 게임 분류 필터
- 오늘의 한 문제(현재 고정된 ‘봬요’ 문제)
- 브라우저 localStorage에 오답 노트와 최근 100회 플레이 기록 저장
- 오답 복습 후 정답을 맞히면 노트에서 제거
- 모바일 대응, 키보드 조작, Escape로 게임 닫기

외부 서버 연결, 회원가입, 공개 배포는 없습니다. 브라우저 데이터 삭제 시 기록도 사라집니다. 문제는 내장된 16개이며 스피드 퀴즈에서는 반복 출제됩니다. 속도 게임은 해설을 읽는 동안에도 시간이 흐릅니다.
