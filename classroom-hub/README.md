# 교실 도구함

로컬에서 동작하는 도구 허브입니다. 설치할 패키지가 없습니다. 일기 저장에는 Node.js 24 이상이 필요합니다.

## 실행

이 폴더에서 `node server.cjs`를 실행하고 http://127.0.0.1:4173 에 접속하세요. 종료는 터미널에서 Ctrl+C입니다. 다른 포트는 PowerShell에서 `$env:PORT=4174`로 지정할 수 있습니다.

`index.html`을 브라우저에서 직접 열어도 기본 기능을 사용할 수 있습니다. 전체화면과 알림음은 브라우저 정책에 따라 제한될 수 있으므로 로컬 서버 사용을 권장합니다.

## 사용

타이머 카드를 누르고 분·초를 설정해 시작합니다. 일시정지·이어서 시작·초기화를 사용할 수 있습니다. 초기화하면 설정한 시간으로 돌아가며, 페이지를 다시 열면 5분·알림음 꺼짐으로 시작합니다. 실행 중에는 시간 입력이 잠깁니다. 전체화면은 버튼 또는 Esc로 나옵니다.

알림음은 기기의 음소거와 음량 설정도 확인하세요. 탭을 닫거나 PC가 절전 상태가 되면 타이머 알림을 보장할 수 없습니다. 탭이 숨겨졌다 돌아오면 경과 시간을 반영합니다.

## 새 도구 추가

1. 새 도구의 HTML·JavaScript를 이 폴더에 추가합니다.
2. `apps.js`에 고유 id, name, description, path 항목을 추가합니다. path는 `new-tool.html`처럼 내부 HTML 경로만 사용합니다.
3. 허브에서 카드가 생성되고 도구가 열리는지 확인합니다. 현재 미리보기 그림은 공통 시계 모양이며 도구가 늘면 별도 그림을 구현할 수 있습니다.

## 구성

- `index.html`, `apps.js`, `hub.js`: 허브·목록
- `timer.html`, `timer.js`: 타이머 화면·동작
- `styles.css`: 공통 토큰·반응형·전체화면
- `server.cjs`: 로컬 파일 서버 및 일기 저장 API

일기 기록은 로컬 SQLite에, 소수 탐험대 최고 기록은 브라우저에 저장합니다. 외부 API·글꼴·음원·분석 서비스를 사용하지 않습니다.

## 나의 일기장

허브의 ‘나의 일기장’ 카드로 들어갑니다. 날짜·제목·기분·내용을 입력해 저장하고, 지난 기록을 선택해 수정하거나 삭제합니다. 제목·내용 검색과 저장하지 않은 변경 경고를 제공합니다. 자동 저장은 없으므로 저장 버튼을 눌러주세요.

`node server.cjs`로 실행해야 저장할 수 있습니다. 기존 서버가 켜져 있으면 종료한 뒤 다시 실행하세요. 기록은 이 폴더의 `data/diary.sqlite`에 저장되며 브라우저를 닫거나 서버를 재시작해도 유지됩니다. 서버를 종료한 뒤 `data` 폴더를 복사하면 백업할 수 있습니다. 복구하려면 서버를 종료하고 백업 파일을 같은 위치에 복사하세요. 데이터 폴더는 Git 추적에서 제외됩니다.

이 일기장은 개인 로컬 사용용이며 비밀번호나 암호화가 없습니다. 같은 컴퓨터에 접근하는 사람은 파일을 읽을 수 있습니다. 서버는 127.0.0.1에서만 실행하며 데이터베이스 파일의 직접 다운로드 및 다른 웹사이트의 저장 요청을 차단합니다. 외부 호스팅에는 배포하지 않습니다.

## PDF 글자 수 세기

허브의 PDF 카드 또는 `pdf-count.html`에서 사용합니다. ES 모듈과 PDF worker 때문에 HTML을 직접 열지 말고 `node server.cjs`로 로컬 서버를 실행하세요. 기존 서버가 실행 중이면 재시작해야 새 `.mjs` 파일 지원이 적용됩니다.

- PDF 하나(최대 50MB)를 선택하거나 끌어 놓으면 공백 포함·제외와 페이지별 글자 수를 표시합니다.
- 줄바꿈·탭은 공백 포함 집계에서도 제외하며 Unicode 코드 포인트 기준으로 셉니다.
- 스캔 이미지의 OCR은 지원하지 않습니다. 텍스트 없는 페이지를 안내합니다.
- PDF 및 결과는 메모리에서만 처리하며 전송·저장하지 않습니다. 새 파일 선택·지우기·새로고침·탭 닫기로 비웁니다.
- PDF.js 6.4.299의 코드·worker·CMap·font·WASM을 `vendor/pdfjs/`에 포함했습니다. 런타임 CDN 연결은 없습니다. 라이선스는 해당 폴더 LICENSE를 확인하세요.
- 페이지 CSP는 외부 연결과 폼 제출을 차단합니다. 로컬 서버는 127.0.0.1에만 바인딩됩니다.

검증: Edge headless 브라우저에서 2쪽 PDF 집계(14자/12자), 빈 페이지 안내, 손상된 PDF, 초기화, 모바일 가로 넘침, 허브 링크, Unicode 집계와 네트워크 요청을 확인했습니다. 테스트에서는 로컬 GET만 발생했습니다. `verify-pdf.cjs`는 이 환경의 번들 Playwright/pdf-lib와 설치된 Edge를 사용하는 검증 스크립트입니다.

## 소수 탐험대

허브의 소수 탐험대 카드에서 엽니다. 캐릭터 선택, 무작위 소수 덧셈·뺄셈 10문제, 힌트, 하트 5개, 경험치와 레벨을 제공합니다. 정수 단위로 계산해 소수 오차를 피합니다. 최고 경험치만 이 브라우저의 localStorage에 저장하며 서버로 보내지 않습니다. 저장이 차단되어도 플레이할 수 있습니다.

`node verify-decimal.cjs`로 허브 연결, 정오답, 10문제 완료, 기록 유지, 체력 소진, 모바일 가로 넘침, JavaScript 오류를 확인했습니다. 검증 서버 주소는 스크립트의 4175 포트입니다.
