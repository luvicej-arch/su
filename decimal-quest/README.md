# 소수 탐험대 · 계정 저장 버전

`npm ci` 후 `npm run build`로 `dist/`를 만듭니다. Vercel 프로젝트 루트는 `decimal-quest`, 출력 폴더는 `dist`입니다.

아이디는 영문 소문자·숫자·밑줄 4~20자, 비밀번호는 8~72자입니다. 실제 이메일은 수집하지 않습니다. 아이디를 예약된 `.invalid` 도메인의 내부 인증 식별자로 변환합니다. 새 전용 Supabase 프로젝트에서는 이메일 확인을 사용하지 않습니다.

비밀번호 분실 시 담당 교사에게 문의합니다. 교사는 Supabase 프로젝트 관리 권한이 있는 운영자에게 해당 아이디의 비밀번호 재설정을 요청합니다. 기존 비밀번호를 조회하거나 공유하지 않습니다. 학생용 화면에는 관리자 키가 없습니다.

학습 기록에는 완료 문제 수, XP, 오답 수, 소요 시간과 문제별 답변을 저장합니다. RLS로 로그인한 본인만 조회·생성·삭제할 수 있습니다. 점수는 자기 학습용이며 클라이언트 계산값이므로 공식 평가나 성적 근거로 사용하지 마세요. 목록은 최근 100회입니다.

공용 기기 보호를 위해 로그인 세션은 메모리에만 보관합니다. 새로고침·탭 종료 후에는 다시 로그인합니다. 저장 실패 시 재시도 버튼이 나타나며 저장 전 페이지를 떠나면 경고합니다.

데이터 저장 위치: Supabase 서울(ap-northeast-2). 운영자는 Supabase 대시보드에서 계정 삭제와 보관 기간을 관리해야 합니다. 계정을 삭제하면 해당 사용자의 기록도 삭제됩니다.
